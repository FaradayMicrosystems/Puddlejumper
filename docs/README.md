# Puddlejumper documentation

Puddlejumper is an Android navigation app for electric vehicles. Every stop on a route shows how far
the car can drive from it, measured along real roads. All units are metric.

Start with [`../HANDOVER.md`](../HANDOVER.md) if you are taking over the project.
